# Markov Chain Composer

This project uses a Markov chain built from a text file to generate new text.

## Web app

Install the web framework and start the local server:

```powershell
py -m pip install -r requirements.txt
py gui.py
```

Open <http://127.0.0.1:5000> in your browser. Upload a `.txt` file, choose the
number of words, and select **Generate**. Use **Download .txt** to save the
result.

## Command line

Run `python project.py` to generate 100 words from a text file and save them to
`generated_output.txt` in the current directory.
